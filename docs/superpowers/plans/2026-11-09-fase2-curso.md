# Fase 2 · Curso "Sistemas fuera del Equilibrio" — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un shell de curso con 9 experimentos (7 nuevos) y panel de ecuación viva, desplegado en Pages.

**Architecture:** `index.html` + `lib/shell.js` enruta por hash e importa `applets/<slug>/applet.js` que exporta `meta` y `mount(root, ctx) → {destroy}`. Modelos puros con `rng` inyectable; motor de discos duros compartido en `applets/_kinetic/disks.js`; caminantes Metrópolis compartidos en `applets/_walkers/metropolis.js`. `lib/liveeq.js` renderiza KaTeX con huecos actualizables.

**Tech Stack:** ES modules, Canvas 2D, KaTeX/marked (cdnjs), node:test, playwright-core.

**Spec:** `docs/superpowers/specs/2026-11-09-fase2-sistemas-fuera-equilibrio-design.md`

## Global Constraints

- Sin build ni dependencias de ejecución; CDN solo cdnjs con versiones fijas (KaTeX 0.16.9, marked 12.0.2).
- Bilingüe ES/EN en toda cadena visible (`i18n.register` por applet, claves `<slug>.*`).
- Colores fijos: teoría `#1f4e9c`, medida `rgba(181,40,30,0.75)`; tokens CSS en `:root` con modo oscuro.
- Cada tarea termina con `npm test` verde y commit en `main` + push.
- Los applets antiguos deben seguir funcionando como páginas sueltas (`applets/<slug>/index.html`).

## Review Focus

1. Cambiar de experimento con la simulación corriendo: el `Loop` anterior debe pararse (`destroy()` cancela rAF) y no dibujar sobre el nuevo canvas. Test en shell: `destroy` llama a `loop.pause()`.
2. KaTeX no disponible (offline): `liveEquation` debe renderizar texto plano con valores, nunca lanzar. Test en liveeq con `katex` indefinido.
3. Parámetros extremos tecleados (N = 0, kT = 0, M > N): `parseNumber` acota; modelos deben tolerar `kT = 0` (Metrópolis: probabilidad 0 al subir) y `M = N`. Tests en kac y metropolis.
4. Hash desconocido (`#/foo`): el shell muestra la portada y no rompe. Test de `parseRoute`.
5. Canvas de 0 px (barra lateral colapsada o pestaña oculta): `Plot.resize` debe ignorar tamaños 0. Test existente de plot no cubre; comprobación manual en humo con viewport 400 px.
